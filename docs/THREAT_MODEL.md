# نموذج التهديدات (مختصر)

التصويت **غير مجهول** بقرار المالك: الورقة مرتبطة بالرقم الجامعي. يُعرض هذا التنبيه للناخب قبل التصويت.

| التهديد | الحماية المنفّذة | الخطر المتبقي |
|---|---|---|
| تكرار التصويت / تزامن | قيد فريد (انتخابات، رقم) + معاملة واحدة + اختبار 12 طلباً متزامناً | — |
| نجاح كاذب أو صوت بلا ورقة | ذرية الدالة؛ الواجهة لا تعلن نجاحاً قبل الخادم | — |
| قراءة الجداول من المتصفح | RLS مفروض + سحب الصلاحيات + اختبارات رفض | — |
| كشف أن رقماً صوّت | رسالة موحدة `not_allowed` للمتصفح | تخمين الأرقام (محدد معدل جزئي) |
| اطلاع المشرف/المالك على اختيارات فرد | لا واجهة لعرض اختيار فرد؛ الوصول بقاعدة البيانات مباشرة فقط | مالك المشروع يستطيع ذلك تقنياً (مقبول) |
| تعديل الأصوات | مشغلات تمنع UPDATE/DELETE على الأوراق | مالك قاعدة البيانات |
| إدخال بعد الإغلاق | وقت الخادم داخل الدالة + مشغل | — |
| تغيير القواعد أثناء التصويت | قفل الإعدادات + لقطة موقّعة بـ SHA-256 | — |
| حساب مشرف مخترق | MFA (TOTP) + تدقيق append-only + تعطيل فوري من المالك | حساب المالك نفسه |
| انتحال الرقم الجامعي | إقرار نزاهة، تجميد الرقم | **غير معالج** في V1 (قرار معتمد) |
