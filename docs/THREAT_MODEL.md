# نموذج التهديدات (مختصر)

| التهديد | الحماية المنفّذة | الخطر المتبقي |
|---|---|---|
| تكرار التصويت / تزامن | PK على (election, id) + معاملة واحدة + اختبار 12 طلباً متزامناً | — |
| نجاح كاذب أو صوت بلا ورقة | ذرية الدالة؛ الواجهة لا تعلن نجاحاً قبل الخادم | — |
| قراءة الجداول من المتصفح | RLS مفروض + سحب الصلاحيات + اختبارات رفض | — |
| كشف أن رقماً صوّت | رسالة موحدة `not_allowed` | تخمين الأرقام (محدد معدل جزئي) |
| ربط الهوية بالصوت (قوية) | لا جدول ربط، ومشغّل يمنعه، وقت مقرّب | مالك `service_role`/DBA، ترتيب الإدراج، WAL |
| تعديل الأصوات | مشغلات تمنع UPDATE/DELETE | مالك قاعدة البيانات |
| إدخال بعد الإغلاق | وقت الخادم داخل الدالة + مشغل | — |
| تغيير القواعد أثناء التصويت | قفل الإعدادات + لقطة موقّعة بـ SHA-256 | — |
| إساءة الصلاحيات | أدوار منفصلة، اعتماد النتائج بشخص آخر، تدقيق append-only | تواطؤ مشرفين |
| انتحال الرقم الجامعي | إقرار نزاهة، تجميد | **غير معالج** في V1 (قرار معتمد) |
| الإكراه/شراء الأصوات | الإيصال لا يكشف الاختيار | — |
