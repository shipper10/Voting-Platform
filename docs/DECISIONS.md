# القرارات المفتوحة (§16) — الافتراضات المنفّذة (قابلة للتعديل باللائحة)

| القرار | ما نُفِّذ |
|---|---|
| الامتناع | يحدده المشرف لكل قسم (`allow_abstain`)، ويُخزَّن صراحة ويُحصى منفصلاً عن الأصوات الصالحة |
| الطريقة A | اختيار واحد افتراضياً (`max_choices=1`, `seats=2`): الأول رئيس والثاني نائب |
| الطريقة B | فصل تام افتراضياً؛ الجمع التراكمي خيار لكل انتخابات (`conflict_policy`) |
| التعادل | `tie_policy` لكل انتخابات: `runoff` (جولة إعادة) أو `declare_tie`؛ لا ترجيح تعسفي |
| النتائج المباشرة | مخفية افتراضياً حتى النشر (`hidden_until_published`) |
| مدة الاحتفاظ | **غير محدد** — يلزم قرار قبل الإطلاق (انظر OPERATIONS) |
| الوصول الاستثنائي | طالب الوصول: مدير/مدقق/مشرف أعلى؛ المعتمدان: اثنان بدور `privacy_approver` مختلفان عن الطالب؛ صلاحية 24 ساعة؛ الكشف مرة واحدة |
| شكاوى الانتحال | `incident_log` + تجميد الرقم؛ لا إبطال أوراق في السرية القوية (انظر PLAN_REVIEW #1) |
| الترتيب التفضيلي | بوردا |
| النجوم | متوسط التقييم؛ مرشح بلا تقييمات لا يفوز |
